# Currency Converter

A modular Python command-line application for converting currencies (USD and EUR to INR).

## Features
- Modular code architecture separating input/menu logic from conversion calculations.
- Clean project structure for easy maintenance and expansion.

## Project Structure
```currency-converter/
│
├── main.py          # Entry point and user menu interface
└── src/
└── converter.py # Core conversion logic and math operations```
